\noindent\textbf{摘要：}本项目围绕 KiTS23 肾脏、肿瘤和囊肿 CT 分割任务，考察“把 segmentation mask 当作条件生成对象”是否能带来有价值的结果。我们实现了 U-Net、SegResNet、conditional VAE 和 conditional diffusion，并在同一 patient-level split 上评估 Dice、IoU、推理时间和采样步数。最终结果比较清楚：判别式模型仍然更强，2.5D U-Net 的测试 Mean Dice 为 0.623；生成式模型中，cVAE 只有 0.201，而直接预测 clean mask 的 x0 diffusion 在 2D 和 2.5D 设置下分别达到 0.436 和 0.534。2.5D 上下文对 diffusion 的提升很明显，但多步 DDIM 采样没有带来稳定增益，25 步推理反而大幅变慢。我们还用 8 次重复采样计算预测熵，在 128 张前景切片上，高熵 top 10\% 像素的错误率约为整体错误率的 5.8 倍。整体来看，x0 diffusion 可以完成分割并提供生成过程与不确定性线索，但还无法替代更快、更稳的判别式分割模型。

\section{引言}

本项目完成 Final Project 中的 Task 2：使用生成式模型完成 KiTS23 数据集上的肾脏、肿瘤和囊肿语义分割，并与传统判别式分割模型进行对比。这个任务本身并不是图像生成，而是密集预测；因此我们关心的问题也不是“能不能生成一张看起来合理的图”，而是生成式建模能不能在像素级分割上给出可用的 mask、可解释的生成过程，以及有意义的不确定性信号。

实验中我们实现并比较了三类模型。U-Net 与 SegResNet 提供判别式 baseline；conditional VAE 作为轻量生成式 baseline；conditional diffusion 是主要分析对象。扩散模型早期采用标准噪声预测目标 $\epsilon_\theta$，训练 loss 能下降，但 Dice 基本起不来。这个失败实验反而很关键：对离散语义 mask 来说，恢复高斯噪声和提高分割重叠并不是一回事。因此最终主实验改为直接预测干净掩码 $x_0$，并用 DiceCE 监督 clean mask。

\section{相关工作与公开 SOTA}

\subsection{医学图像分割 Baseline}

U-Net 仍然是医学图像分割里最重要的基线之一。它的优势不只是结构简单，而是 encoder--decoder 和 skip connection 对像素级定位非常友好：下采样路径提供语义信息，上采样路径恢复空间分辨率，浅层特征还能把边界细节带回来 \cite{ronneberger2015unet}。KiTS 系列高分方案也基本沿着这条路线发展，包括 3D U-Net、SegResNet、nnU-Net、SwinUNETR 或自动搜索得到的变体。

\subsection{扩散模型用于分割}

DDPM 将生成过程写成从高斯噪声逐步去噪的逆过程 \cite{ho2020ddpm}；DDIM 则把采样过程改写为可以跳步的非马尔可夫形式，从而在质量和速度之间折中 \cite{song2020ddim}。医学分割里的 MedSegDiff 和 MedSegDiff-V2 说明，扩散模型也可以用于条件分割，而不只是自然图像生成 \cite{wu2022medsegdiff,wu2023medsegdiffv2}。本项目借鉴的是这条思路：mask 不再只是一个网络输出，而是一个在图像条件下逐步生成的对象。不过我们没有照搬完整 MedSegDiff 结构，而是实现了更轻量的 conditional U-Net denoiser，并比较了 epsilon prediction 和 x0 prediction 的差异。

\subsection{KiTS23 公开高分方案}

公开 KiTS23 高分方案与本项目不是同一个量级的设置。第一名 NVIDIA 方案使用 3D 自动分割框架，候选模型包括 SegResNet、DiNTS 和 SwinUNETR，并叠加 5-fold cross validation、sliding-window inference、kidney region cropping、connected component post-processing 和多模型 ensemble；其官方隐藏测试集 average Dice 为 0.835，surface Dice 为 0.723 \cite{myronenko2023kits23}。第二名方案使用多尺度 3D U-Net，把低分辨率和全分辨率预测通过后处理融合，average Dice 为 0.820，surface Dice 为 0.712 \cite{uhm2023kits23}。另有 2.5D ResUNet ensemble 方案采用 coarse-to-fine 框架，在 kidney、tumor、cyst 上分别报告 Dice 0.954、0.792、0.691 \cite{chen2023kits23}.

这些方法的共同点很明确：充分利用 3D/2.5D 上下文，用交叉验证和 ensemble 降低方差，用 kidney crop 缩小搜索范围，再用连通域后处理压掉明显不合理的假阳性。我们没有复现这一整套 leaderboard pipeline。原因一方面是课程重点在生成式密集预测，另一方面是本项目需要在有限时间内同时训练判别式 baseline、cVAE 和 diffusion。后文把 SOTA 列出来，是为了说明差距来自哪些具体设计，而不是把我们的 2D/2.5D 单模型结果和官方榜单直接排名。

\section{数据集与预处理}

\subsection{KiTS23 数据集}

KiTS23 是肾脏肿瘤分割挑战数据集，包含腹部 CT 扫描及对应的体素级分割标注，官方仓库提供数据下载工具、评价指标和 ranking 代码 \cite{kits23repo}。标注类别包括：0 为背景，1 为肾脏，2 为肿瘤，3 为囊肿。

\subsection{2D 切片构建}

按照作业要求，项目沿 axial 轴将 3D CT 体数据切分为 2D 切片。主实验使用单切片输入，以降低扩散模型训练与采样的显存成本，并便于与 U-Net、SegResNet 和 cVAE 使用统一输入设置进行公平比较。扩展实验进一步使用 2.5D 输入，即将当前切片及其相邻上下切片作为 3 通道输入，用于分析跨层上下文对判别式和生成式模型的影响。

\subsection{HU 窗位窗宽与归一化}

CT 原始强度先进行 HU 窗位窗宽裁剪。设窗位为 $c$，窗宽为 $w$，裁剪范围为
\[
[c-\frac{w}{2}, c+\frac{w}{2}].
\]
本项目使用腹部 CT 常用窗口设置 $c=40,w=400$。裁剪后将图像线性归一化到 $[0,1]$，并将切片 resize 到 $256\times256$。

切片筛选采用 foreground-or-context 策略：保留含 kidney、tumor 或 cyst 的前景切片，同时保留前景附近少量上下文切片，并对纯背景切片进行稀疏采样。这样可以避免训练集被大量无器官背景切片主导，同时保留模型判断背景的能力。

\subsection{数据划分}

为避免同一患者的不同切片同时出现在训练集和测试集中，数据划分按患者 ID 完成，而不是按切片随机划分。最终实验使用 100 例病例，划分比例为训练集 70\%、验证集 15\%、测试集 15\%。数据统计见表 \ref{tab:data_statistics}。

\subsection{判别式分割 Baseline}

判别式 baseline 直接学习从输入图像到分割掩码的映射：
\[
\hat{y}=f_\theta(x).
\]
判别式部分使用 U-Net 和一个轻量 SegResNet-style residual encoder--decoder。需要说明的是，这里的 SegResNet 不是把分类 ResNet 直接改成分割网络，而是在 U-Net-like 的下采样/上采样框架中，把普通卷积块替换为 residual block。U-Net 的局部模块是两层卷积；SegResNet 的局部模块学习残差 $F(x)$ 并与输入相加，如果通道数不一致，则用 $1\times1$ convolution 做 skip projection。两者都使用 DiceCE 损失，使训练同时关注像素分类和区域重叠。

\subsection{条件 VAE 分割模型}

条件 VAE 将分割掩码视为条件生成目标。给定图像 $x$ 和真实掩码 $y$，编码器近似后验分布 $q_\phi(z|x,y)$，解码器根据图像条件和潜变量生成掩码：
\[
z \sim q_\phi(z|x,y), \quad \hat{y}=p_\theta(y|x,z).
\]
训练目标由重建损失和 KL 散度组成：
\[
\mathcal{L}_{\mathrm{cVAE}} = \mathcal{L}_{\mathrm{seg}}(\hat{y}, y)
+ \beta D_{\mathrm{KL}}\left(q_\phi(z|x,y)\|p(z)\right).
\]
这里 KL 项对齐的是 $q_\phi(z|x,y)$ 和 $p(z)$，而不是 $p(z|y)$。原因很直接：测试时 $y$ 正是要预测的答案，不能作为 prior 的条件。更强的 cVAE 可以额外学习 $p_\psi(z|x)$，但本实验采用的是标准正态先验。最终评估时使用 deterministic prior $z=0$，以减少随机采样带来的指标方差。这个设计简单，但也带来明显的 posterior-prior gap：训练时 encoder 看得到真实 mask，测试时只能依赖先验生成。

\subsection{条件扩散分割模型}

设真实 one-hot 掩码为 $m_0$，扩散前向过程为
\[
q(m_t|m_0)=\sqrt{\bar{\alpha}_t}m_0+\sqrt{1-\bar{\alpha}_t}\epsilon,\quad
\epsilon\sim\mathcal{N}(0,I).
\]
模型接收图像 $x$、加噪掩码 $m_t$ 和时间步 $t$，输出与掩码同尺寸的张量。早期实验使用 DDPM 常见的噪声预测目标：
\[
\mathcal{L}_{\mathrm{noise}} =
\left\|\epsilon-\epsilon_\theta(x,m_t,t)\right\|_2^2.
\]
这个目标在训练中数值收敛很快，但验证 Dice 长期接近 0。也就是说，噪声 MSE 变小并不自动意味着分割 mask 变好。对 KiTS23 这类任务，真正重要的是 kidney、tumor、cyst 的区域是否重叠；单纯恢复加到 mask 上的高斯噪声，会被大量背景像素主导，小目标得到的语义监督很弱。

最终主模型改为 x0-diffusion：网络直接预测干净掩码 logits $\hat{m}_0=f_\theta(x,m_t,t)$，训练目标为
\[
\mathcal{L}_{\mathrm{x0}} =
\mathcal{L}_{\mathrm{DiceCE}}(\hat{m}_0,m_0)
+ \lambda \left\|\mathrm{softmax}(\hat{m}_0)-m_0\right\|_2^2.
\]
该设计保留了“从 noisy mask 迭代生成 clean mask”的形式，但训练信号直接落在分割空间上。网络输出的是 clean mask logits，可以直接计算 DiceCE；同时 softmax 后的 MSE 约束预测概率贴近 one-hot mask。这样优化目标和最终评估的 Dice/IoU 更接近。

\subsection{采样策略与不确定性}

推理阶段从随机噪声掩码 $m_T$ 出发，每一步都预测一个 $\hat{m}_0$，再由当前 $m_t$ 和 $\hat{m}_0$ 反推出噪声方向 $\hat{\epsilon}_t$，用 DDIM 更新到更早的时间步。中间步骤的 $\hat{m}_0$ 不直接作为最终输出，而是用来构造下一步更干净的 mask 状态；最后一步的 $\hat{m}_0$ 才用于得到最终 segmentation。完整 DDPM 采样成本较高，因此实验采用 DDIM-style 跳步采样，并比较 $S\in\{1,5,10,25\}$。此外，生成式模型可以对同一输入重复采样，得到多个候选分割结果，用平均预测熵
\[
H(x)=-\sum_c \bar{p}_c(x)\log\bar{p}_c(x)
\]
可视化不确定性。

\subsection{评价指标}

测试集上汇报 Dice Score 和 IoU。对类别 $c$，Dice 和 IoU 定义为
\[
\mathrm{Dice}_c=\frac{2|\hat{Y}_c\cap Y_c|}{|\hat{Y}_c|+|Y_c|},\quad
\mathrm{IoU}_c=\frac{|\hat{Y}_c\cap Y_c|}{|\hat{Y}_c\cup Y_c|}.
\]
多类结果分别计算 kidney、tumor、cyst 的 Dice，并给出三类前景平均值。对生成式模型额外统计单张切片平均推理时间和不同采样步数下的速度变化。

\section{讨论与局限}

从绝对数值看，本项目距离 KiTS23 高分方案还有明显差距；从课程目标看，实验覆盖了生成式分割建模、判别式 baseline、不同生成 setting、训练曲线、生成过程可视化和不确定性分析。我们认为这个项目最有价值的部分不是刷新 KiTS23 指标，而是诚实地展示生成式模型用于密集预测时会遇到的问题：目标函数是否对齐、采样步数是否值得、小目标是否能稳定生成、以及不确定性图到底能提供多少信息。

主要观察如下：
\begin{itemize}
    \item 判别式模型仍然是更强的基线。测试集上 2D SegResNet 的 Mean Dice 为 0.572，2.5D U-Net 为 0.623；2.5D x0 diffusion 5 步采样为 0.534。
    \item 生成式模型的价值不主要体现在单点 Dice。扩散模型可以展示 denoising trajectory，也可以通过重复采样给出预测熵图；在 128 张前景切片上，高熵 top 10\% 像素的错误率约为整体错误率的 5.8 倍。
    \item 生成目标设计非常关键。标准 epsilon prediction 在本任务上几乎失败，而 x0 prediction 明显更可用，说明医学分割中的 diffusion 不能简单照搬自然图像生成的噪声预测目标。
    \item 小目标仍是瓶颈。2.5D diffusion 将 5 步采样的 cyst Dice 从 2D 的 0.078 提升到 0.101，但仍低于 2.5D U-Net 的 0.242。
\end{itemize}

主要局限也比较清楚。第一，实验采用 2D/2.5D 切片，而不是完整 3D volume，跨切片上下文仍然有限。第二，只使用 100 例病例，没有做 5-fold cross validation。第三，没有加入 kidney foreground crop、connected component post-processing 或 ensemble，这些都是 KiTS23 高分方案中非常有效的工程组件。第四，扩散模型仍在 pixel-space mask 上采样，推理成本高，多步采样收益有限。第五，cVAE 的先验生成能力较弱，说明简单潜变量模型不足以处理这个多类别小目标分割任务。


\section{结论}

本文完成了 KiTS23 四类分割任务上的判别式 baseline、conditional VAE 和 conditional diffusion 对比。最好的判别式结果来自 2.5D U-Net，测试 Mean Dice 为 0.623；生成式模型中，cVAE 只有 0.201，2D x0 diffusion 5 步采样达到 0.436，2.5D x0 diffusion 进一步达到 0.534。这个结果说明，扩散式 mask generation 明显优于 cVAE，且相邻切片上下文对生成式模型同样有效。

同时，实验也给出了边界：当前生成式模型没有超过判别式模型，推理速度也更慢。采样步数消融显示，2.5D diffusion 的 1 步和 5 步结果接近，继续增加步数没有稳定提升。重复采样熵图则提供了额外的不确定性线索，高熵区域更容易出现预测错误。综合来看，x0 diffusion 在本任务上是一个可用但尚不占优的分割生成模型；它的价值更多体现在生成过程和不确定性分析，而不是替代 U-Net/SegResNet 这类成熟判别式模型。

后续如果继续推进，优先方向不应只是延长 diffusion 训练，而应补上 KiTS23 高分方案中已经验证有效的组件：更完整的 3D/2.5D 上下文、region-based label、foreground crop、类别重加权、简单连通域后处理，以及将 diffusion 作为判别式模型之后的 mask refinement。这样可能比从随机 mask 完整生成更符合医学分割对精度和效率的要求。
