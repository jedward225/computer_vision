\section{项目概述}

本项目完成 Final Project 中的 Task 2：使用生成式模型完成 KiTS23 数据集上的肾脏、肿瘤和囊肿语义分割，并与传统判别式分割模型进行对比。与直接学习映射 $f_\theta(x)\rightarrow y$ 的 U-Net 类方法不同，本项目将分割掩码视为需要生成的目标变量，将语义分割建模为以 CT 图像为条件的掩码生成过程。

项目实现并比较了三类模型：U-Net 与 SegResNet 作为判别式 baseline，conditional VAE 作为轻量生成式 baseline，conditional diffusion 作为主生成式模型。扩散模型在早期实验中采用噪声预测目标 $\epsilon_\theta$，但该设置虽然能快速降低噪声 MSE，却不能稳定提升分割 Dice；最终主实验改为直接预测干净掩码 $x_0$ 的 x0-diffusion，使训练目标与分割指标更一致。

本项目重点分析以下问题：
\begin{itemize}
    \item 生成式分割模型在医学图像分割中的精度、速度和训练成本；
    \item 噪声预测扩散与 x0 预测扩散在密集预测任务中的差异；
    \item 不同生成步数对扩散模型精度和推理时间的影响；
    \item 生成式模型通过迭代生成过程和重复采样表达不确定性的能力。
\end{itemize}

\section{相关工作与公开 SOTA}

\subsection{医学图像分割 Baseline}

U-Net 是医学图像分割中最经典的判别式架构之一，其编码器-解码器结构结合 skip connection，在小规模标注数据上仍能取得较强定位能力 \cite{ronneberger2015unet}。KiTS 系列挑战的高分方案也大多建立在 U-Net、3D U-Net、SegResNet、nnU-Net 或其变体之上，而不是纯生成式模型。这说明在医学分割任务中，强判别式模型仍然是必须纳入比较的基线。

\subsection{扩散模型用于分割}

DDPM 将数据生成建模为从高斯噪声逐步去噪的逆过程 \cite{ho2020ddpm}，DDIM 进一步给出了更快的非马尔可夫采样方式，使采样步数可以在质量和速度之间折中 \cite{song2020ddim}。在医学图像分割中，MedSegDiff 将扩散模型用于条件分割，强调 step-wise 条件编码和高频噪声处理 \cite{wu2022medsegdiff}；MedSegDiff-V2 则进一步引入 Transformer 机制，在多种医学分割任务上验证扩散式分割的潜力 \cite{wu2023medsegdiffv2}。本项目借鉴其核心思想：不是直接一步输出分割，而是将 mask 作为生成对象，通过条件去噪得到最终分割。

\subsection{KiTS23 公开高分方案}

公开 KiTS23 高分方案与本项目的设置有明显差异。第一名 NVIDIA 方案使用 MONAI Auto3DSeg，自动训练 SegResNet、DiNTS 和 SwinUNETR 等 3D 模型，并使用 5-fold cross validation、sliding-window inference、kidney region cropping、connected component post-processing 和多模型 ensemble；最终在 KiTS23 官方隐藏测试集上达到 average Dice 0.835、surface Dice 0.723 \cite{myronenko2023kits23}。第二名方案使用多尺度 3D U-Net，将低分辨率和全分辨率预测通过任务相关后处理融合，在官方测试集上达到 average Dice 0.820、surface Dice 0.712 \cite{uhm2023kits23}。另有 2.5D ResUNet ensemble 方案采用 coarse-to-fine 框架，在 kidney、tumor、cyst 上分别报告 Dice 0.954、0.792、0.691 \cite{chen2023kits23}.

因此，公开 SOTA 的共同特点是：利用 3D 或 2.5D 上下文、全量或接近全量病例、交叉验证、多模型集成、器官区域裁剪和连通域后处理。本项目为了满足课程中“生成式密集预测”的核心要求，优先实现和分析生成式分割范式，因此采用 2D 切片和单模型设置。后文的 SOTA 对比主要用于解释差距来源，而不是声称与挑战榜单进行完全公平比较。

\section{数据集与预处理}

\subsection{KiTS23 数据集}

KiTS23 是肾脏肿瘤分割挑战数据集，包含腹部 CT 扫描及对应的体素级分割标注，官方仓库提供数据下载工具、评价指标和 ranking 代码 \cite{kits23repo}。训练数据中每个病例包含 \texttt{imaging.nii.gz} 和 \texttt{segmentation.nii.gz} 两个 NIfTI 文件。标注类别包括：0 为背景，1 为肾脏，2 为肿瘤，3 为囊肿。

\subsection{2D 切片构建}

按照作业要求，项目沿 axial 轴将 3D CT 体数据切分为 2D 切片。主实验使用单切片输入，以降低扩散模型训练与采样的显存成本，并便于与 U-Net、SegResNet 和 cVAE 使用统一输入设置进行公平比较。扩展实验进一步使用 2.5D 输入，即将当前切片及其相邻上下切片作为 3 通道输入，用于分析跨层上下文对判别式和生成式模型的影响。

\subsection{HU 窗位窗宽与归一化}

CT 原始强度先进行 HU 窗位窗宽裁剪。设窗位为 $c$，窗宽为 $w$，裁剪范围为
\[
[c-\frac{w}{2}, c+\frac{w}{2}].
\]
本项目使用腹部 CT 常用窗口设置 $c=40,w=400$。裁剪后将图像线性归一化到 $[0,1]$，并将切片 resize 到 $256\times256$。

切片筛选采用 foreground-or-context 策略：保留含 kidney、tumor 或 cyst 的前景切片，同时保留前景附近少量上下文切片，并对纯背景切片进行稀疏采样。这样可以避免训练集被大量无器官背景切片主导，同时保留模型判断背景的能力。

\subsection{数据划分}

为避免同一患者的不同切片同时出现在训练集和测试集中，数据划分按患者 ID 完成，而不是按切片随机划分。最终实验使用 100 例病例，划分比例为训练集 70\%、验证集 15\%、测试集 15\%。数据统计见表 \ref{tab:data_statistics}。

\subsection{与官方 KiTS23 评测的差异}

需要说明的是，本项目的标签与官方 KiTS23 challenge 的最终评测区域并不完全一致。课程作业要求可以保留多类标签，因此本项目直接预测 background、kidney、tumor、cyst 四类互斥类别，并报告 kidney、tumor、cyst 三类 Dice 的平均值。公开 KiTS23 高分方案常将任务转为重叠区域的 multi-label segmentation，例如 kidney+mass、mass、tumor 三个区域。这种定义更适合官方 ranking，也更容易利用器官与病灶的层级关系。由于评测区域、训练数据规模和 2D/3D 输入设置都不同，本项目结果不能与官方 leaderboard 数字直接等价比较。

\section{方法}

\subsection{整体流程}

本项目的整体流程如下：首先将 3D CT 体数据预处理为 2D axial 切片，并将 segmentation label 转为 one-hot mask；判别式 baseline 直接学习 $x\rightarrow y$；生成式模型则学习条件分布 $p(y|x)$。对于 diffusion，训练时从真实 mask $m_0$ 采样时间步 $t$ 并生成加噪 mask $m_t$，网络接收 $[x,m_t,t]$ 预测干净 mask 或噪声；推理时从随机噪声 mask 开始，通过 DDIM-style 更新得到最终 mask。该流程满足作业中“以输入图像为条件，生成对应分割掩码”的要求。

\subsection{判别式分割 Baseline}

判别式 baseline 直接学习从输入图像到分割掩码的映射：
\[
\hat{y}=f_\theta(x).
\]
本项目使用 U-Net 和 SegResNet-style residual network。U-Net 通过编码器-解码器结构和 skip connection 融合局部细节与高级语义；SegResNet 在卷积块中引入残差连接，作为更强的医学图像分割 baseline。两者均使用 DiceCE 损失，以同时优化区域重叠和逐像素分类。

\subsection{条件 VAE 分割模型}

条件 VAE 将分割掩码视为条件生成目标。给定图像 $x$ 和真实掩码 $y$，编码器近似后验分布 $q_\phi(z|x,y)$，解码器根据图像条件和潜变量生成掩码：
\[
z \sim q_\phi(z|x,y), \quad \hat{y}=p_\theta(y|x,z).
\]
训练目标由重建损失和 KL 散度组成：
\[
\mathcal{L}_{\mathrm{cVAE}} = \mathcal{L}_{\mathrm{seg}}(\hat{y}, y)
+ \beta D_{\mathrm{KL}}\left(q_\phi(z|x,y)\|p(z)\right).
\]
测试时不能使用真实掩码，因此从先验 $p(z)$ 生成分割结果。本实验采用 deterministic prior $z=0$ 进行最终评估，以减少随机采样带来的指标方差。

\subsection{条件扩散分割模型}

设真实 one-hot 掩码为 $m_0$，扩散前向过程为
\[
q(m_t|m_0)=\sqrt{\bar{\alpha}_t}m_0+\sqrt{1-\bar{\alpha}_t}\epsilon,\quad
\epsilon\sim\mathcal{N}(0,I).
\]
模型接收图像 $x$、加噪掩码 $m_t$ 和时间步 $t$，输出与掩码同尺寸的张量。早期实验使用 DDPM 常见的噪声预测目标：
\[
\mathcal{L}_{\mathrm{noise}} =
\left\|\epsilon-\epsilon_\theta(x,m_t,t)\right\|_2^2.
\]
该目标在训练中数值收敛很快，但验证 Dice 长期接近 0，说明模型主要学会了从 $m_t$ 中恢复噪声，而没有学到足够强的图像条件分割能力。

最终主模型改为 x0-diffusion：网络直接预测干净掩码 logits $\hat{m}_0=f_\theta(x,m_t,t)$，训练目标为
\[
\mathcal{L}_{\mathrm{x0}} =
\mathcal{L}_{\mathrm{DiceCE}}(\hat{m}_0,m_0)
+ \lambda \left\|\mathrm{softmax}(\hat{m}_0)-m_0\right\|_2^2.
\]
该设计保留了以噪声掩码为输入、迭代生成掩码的形式，同时让优化目标直接对齐语义分割指标。

\subsection{采样策略与不确定性}

推理阶段从随机噪声掩码 $m_T$ 出发，逐步预测 $m_0$ 并更新中间状态。完整 DDPM 采样成本较高，因此本项目采用 DDIM-style 采样，并比较 $S\in\{1,5,10,25\}$ 的生成步数。生成式模型还可以对同一输入重复采样得到多个候选分割结果，用平均预测熵
\[
H(x)=-\sum_c \bar{p}_c(x)\log\bar{p}_c(x)
\]
可视化不确定性。

\subsection{训练配置}

所有模型均在 NVIDIA A100 环境上训练。优化器使用 AdamW，训练时开启混合精度。主要超参数见表 \ref{tab:hparams}，完整配置保存在 \texttt{src/configs/}。

模型选择以验证集 Mean Dice 为准保存 best checkpoint。U-Net、SegResNet 和 cVAE 训练 100 epoch；x0 diffusion 训练 80 epoch，验证时使用 5 步采样以控制评估时间。由于扩散模型每次推理需要多次 denoising 前向传播，它的训练和评估成本明显高于一步式分割网络。因此报告中除 Dice/IoU 外，额外记录 \texttt{ms/image}，用于量化生成步数带来的推理开销。

\subsection{评价指标}

测试集上汇报 Dice Score 和 IoU。对类别 $c$，Dice 和 IoU 定义为
\[
\mathrm{Dice}_c=\frac{2|\hat{Y}_c\cap Y_c|}{|\hat{Y}_c|+|Y_c|},\quad
\mathrm{IoU}_c=\frac{|\hat{Y}_c\cap Y_c|}{|\hat{Y}_c\cup Y_c|}.
\]
多类结果分别计算 kidney、tumor、cyst 的 Dice，并给出三类前景平均值。对生成式模型额外统计单张切片平均推理时间和不同采样步数下的速度变化。

cVAE 的测试结果最低，说明后验重建能力不能直接转化为先验生成能力。训练时 encoder 可以看到真实 mask，测试时只能从先验 $z=0$ 生成，存在明显 posterior-prior gap。x0 diffusion 虽然仍低于判别式 baseline，但比 cVAE 更稳定，说明逐步条件去噪比一次性潜变量解码更适合本项目的分割生成任务。

\subsection{生成目标设计对比}

表 \ref{tab:diffusion_objective} 对比了两种扩散训练目标。epsilon diffusion 的训练目标为预测高斯噪声，训练 loss 能够下降，但验证 Dice 长期接近 0，说明其目标与分割结果不够对齐。x0 diffusion 直接预测干净掩码，并用 DiceCE 监督，因此显著提升分割性能。

epsilon 目标失败的关键原因在于：segmentation mask 是离散语义结构，而标准高斯加噪后的 $m_t$ 是连续值；当训练目标只要求恢复噪声时，模型可以降低 MSE，却不一定学到“哪些像素属于 kidney/tumor/cyst”。尤其在类别极不均衡时，噪声预测损失被大量背景像素主导，小病灶区域的语义监督很弱。x0 目标直接让网络输出 clean mask logits，并叠加 DiceCE，因此梯度更直接地作用在分割边界和小目标上。

\subsection{失败案例分析}

从定量结果和可视化可以观察到以下失败模式：
\begin{itemize}
    \item diffusion 对 kidney 定位较稳定，但对小病灶仍不稳定。2.5D diffusion 5 步采样下 kidney Dice 为 0.891，而 tumor 和 cyst Dice 分别为 0.610 和 0.101。
    \item 相邻切片上下文能显著改善生成式模型。2D diffusion 的 tumor/cyst Dice 为 0.449/0.032，2.5D diffusion 提升到 0.610/0.101，但 cyst 仍低于 2.5D U-Net 的 0.242。
    \item 可视化中仍能看到漏检现象，尤其是小面积前景切片上，模型可能只生成 kidney 或直接输出接近全背景的 mask。
\end{itemize}

\section{讨论与局限}

从绝对数值看，本项目与 KiTS23 公开高分方案仍有明显差距；从课程大作业目标看，本项目完成了生成式分割建模、判别式 baseline、不同生成 setting 对比、训练曲线、生成过程可视化和不确定性分析。因此，本项目的主要价值不是刷新 KiTS23 指标，而是回答“生成式模型用于密集预测时实际会遇到什么问题”。

本项目观察到的主要现象如下：
\begin{itemize}
    \item 判别式模型仍然是更强的工程 baseline。测试集上 2D SegResNet 的 Mean Dice 为 0.572，2.5D U-Net 为 0.623；2.5D x0 diffusion 5 步采样为 0.534。
    \item 生成式模型的优势不在单点精度，而在输出分布建模。扩散模型可以展示 denoising trajectory，也可以通过重复采样给出不确定性图，这对边界模糊或小病灶复核有潜在意义。
    \item 生成目标设计非常关键。标准 epsilon prediction 在本任务上几乎失败，而 x0 prediction 显著提升 Dice，说明医学分割中的扩散模型不能简单照搬自然图像生成的训练目标。
    \item 小目标仍是生成式模型的核心瓶颈。2.5D diffusion 将 cyst Dice 从 2D 的 0.032 提升到 0.101，但仍低于 2.5D U-Net 的 0.242。
\end{itemize}

本项目的主要局限包括：第一，采用 2D 切片而非完整 3D 体数据，损失跨切片空间上下文；第二，只使用 100 例病例，且未进行 5-fold cross validation；第三，没有使用 kidney foreground crop、connected component post-processing 或模型 ensemble；第四，扩散模型在 pixel-space mask 上采样，推理成本高，且多步采样收益有限；第五，cVAE 在后验重建时表现较好，但使用先验生成时性能明显下降。

\section{进一步优化方向}

如果继续提升成绩，优先级最高的不是继续堆 diffusion epoch，而是补足 KiTS23 高分方案中已经被证明有效的医学分割工程技巧：
\begin{itemize}
    \item 进一步强化 2.5D/3D 上下文。当前 2.5D U-Net 和 2.5D diffusion 均优于对应 2D 设置，后续可以扩大相邻切片范围或改用轻量 3D diffusion。
    \item 改为 region-based label。参考 KiTS23 官方高分方案，将输出定义为 kidney+mass、mass、tumor 等重叠区域，再还原为互斥标签，有助于表达器官和病灶的层级关系。
    \item 加入类别重加权或 focal loss。当前 cyst 极弱，应该提高小目标类别权重，或对前景 patch 进行更强采样。
    \item 做简单后处理。去除小连通域、保留最大 kidney connected components、限制 tumor/cyst 出现在 kidney neighborhood 附近，可能减少假阳性。
    \item 使用 foreground crop 或两阶段框架。先粗定位 kidney 区域，再在局部区域进行精分割，可以减少背景干扰。
    \item 尝试 latent diffusion 或 mask refinement。将 diffusion 用作判别式模型输出后的 refinement，而不是从随机 mask 完整生成，可能在速度和精度之间更合理。
\end{itemize}

当前最值得展示的扩展结果是 2.5D 条件扩散：它说明跨层解剖上下文不仅能提升判别式 U-Net，也能提升生成式 mask generation。结合采样步数消融、不确定性图和 SOTA 方法差距分析，可以较完整地展示生成式密集预测的优势与局限。

\section{结论}

本项目围绕 KiTS23 肾脏肿瘤分割任务，构建了判别式 baseline、条件 VAE 和条件扩散分割模型，并从精度、速度、生成过程和不确定性等角度比较生成式与判别式方法。最终测试结果显示，2D SegResNet 和 2D U-Net 的 Mean Dice 分别为 0.572 和 0.570，扩展实验中的 2.5D U-Net 进一步达到 0.623；生成式模型中，2D x0 diffusion 5 步采样达到 0.434，明显优于 cVAE 的 0.201，2.5D x0 diffusion 进一步提升到 0.534。采样步数消融表明，更多 denoising 步数并不必然带来更高 Dice，2.5D diffusion 在 1 步和 5 步下均取得较好结果。与公开 KiTS23 高分方案相比，本项目的主要差距来自 2D/2.5D 单模型、无 ensemble、无强后处理和训练数据规模较小。整体来看，生成式模型能够完成医学图像分割并提供生成轨迹和不确定性信息；加入相邻切片上下文后，其精度明显提升，但在当前设置下仍不能完全替代高效稳定的判别式分割模型。
